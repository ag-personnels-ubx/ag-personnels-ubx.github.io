Fonctionnement des AG

Comment une AG est préparée, comment elle se déroule et comment on y décide.

Qui peut venir · Ordre du jour · Déroulement · Votes · Après l'AG

Qui peut venir

L'AG est ouverte à tous les personnels de l'université, quel que soit leur statut (titulaires, contractuels, doctorants, vacataires…), syndiqués ou non.

Ordre du jour

  1. Chacun peut proposer un point sur la page Propositions d'ordre du jour.
  2. Les propositions sont closes deux jours avant l'AG.
  3. L'équipe d'organisation construit l'ordre du jour en commençant par les points les plus soutenus.
  4. L'ordre du jour provisoire est publié sur la page d'accueil.
  5. En début de séance, l'AG valide l'ordre du jour et peut le modifier.

Déroulement d'une séance

Les rôles

  • Présidence de séance : donne la parole et fait respecter l'ordre du jour.
  • Prise de notes : rédige le compte rendu.
  • Gardien du temps : signale quand le temps prévu pour un point est dépassé.

Ces rôles changent à chaque AG. Toute personne volontaire peut les prendre.

La prise de parole

  • On lève la main pour s'inscrire sur la liste des interventions.
  • Les interventions sont limitées à 2 ou 3 minutes.
  • Priorité est donnée aux personnes qui ne se sont pas encore exprimées.

Votes

  • Toute personne présente peut voter.
  • Le vote se fait à main levée : pour, contre, abstention.
  • Une motion est adoptée à la majorité des suffrages exprimés.
  • Sur demande, un vote à bulletin secret peut être organisé.

Les résultats sont publiés sur la page Infos générales.

Après l'AG

  • Le compte rendu est diffusé sous une semaine et déposé sur la page AG et comptes rendus.
  • Les tâches décidées sont reportées sur la page Action en cours.
